# 별빛 생존자 (Starfall Survivors)

모바일 브라우저용 도트 그래픽 생존 액션 게임. 빌드 과정 없는 순수 HTML5 Canvas + JS, 2인 온라인 협동 지원.

- `data.js` 스프라이트(문자열 도트), 캐릭터/무기/패시브/적/웨이브 데이터
- `engine.js` 게임 루프, 전투, 스폰, 렌더링 (플레이어 여러 명 지원)
- `ui.js` 메뉴·레벨업·보물상자·상점 화면, 입력
- `net.js` 온라인 협동: 방 만들기/참가, 호스트 스냅샷 전송, 게스트 클라이언트
- `server.js` 정적 파일 서버 + 4자리 방 코드로 두 폰을 이어주는 WebSocket 중계 (`/ws`)

## 협동 구조
방장 폰이 게임 전체를 계산한다. 게스트는 자기 캐릭터 위치만 직접 움직여 보내고,
방장이 초당 20회 보내는 스냅샷(적·투사체는 바이너리)을 받아 부드럽게 보간해 그린다.
경험치와 레벨은 공유하고, 레벨업·보물상자 보상은 각자 고른다. 둘 중 한 명이 선택 중이면 잠시 멈춘다.
쓰러지면 동료가 곁에 2.5초 서 있거나 20초가 지나면 부활하고, 둘 다 쓰러지면 끝난다.

## 실행
```
npm install
STATIC_DIR=. PORT=8080 node server.js
```
밸런스 시뮬레이션: `?sim=1&chars=knight,mage&god=0&vac=1&duo=mage` (`duo`는 봇 동료, 결과는 `#simout`에 JSON).
