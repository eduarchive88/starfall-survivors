# 별빛 생존자 (Starfall Survivors)

모바일 브라우저용 도트 그래픽 생존 액션 게임. 빌드 과정 없는 순수 HTML5 Canvas + JS, 최대 4인 온라인 협동 지원.

## 스테이지
15분을 버티면 클리어, 클리어하면 다음 스테이지가 열린다 (10개). 스테이지마다 바닥·장식·몬스터(색 변형 + 거미/전갈/임프/버섯)·보스 3마리·날씨가 다르고,
묘지/동굴/공허는 시야가 어둡고 화산/공허는 운석이 떨어진다. 난이도(`hp`·`dmg`·`dens`)는 스테이지 초반엔 일부만, 후반으로 갈수록 전부 적용된다. 보상 골드는 스테이지마다 ×0.3씩 늘어난다.

- `data.js` 스프라이트(문자열 도트), 캐릭터/무기/패시브/적 데이터, 스테이지(`STAGES`, `stageWave`, `stageEvents`)
- `engine.js` 게임 루프, 전투, 스폰, 렌더링 (플레이어 여러 명 지원)
- `ui.js` 메뉴·레벨업·보물상자·상점 화면, 입력
- `net.js` 온라인 협동: 방 만들기/참가, 호스트 스냅샷 전송, 게스트 클라이언트
- `server.js` 정적 파일 서버 + 4자리 방 코드로 최대 4대의 폰을 묶는 WebSocket 중계 (`/ws`). 방장=슬롯 0, 게스트=슬롯 1~3. 게스트→방장 메시지엔 `from`을 붙이고, 방장→게스트는 JSON `to`(0=모두) 또는 바이너리 첫 바이트로 대상을 고른다

## 특별 상품 (상점)
- 슬롯 확장 (영구, 환불 없음): 1단계 100,000골드 → 무기 슬롯 6→7, 2단계 150,000골드 → 패시브 슬롯 8→9. `save.slots`
- 보급 상자 (1회용): 3,000골드. 다음 게임 시작 직후 보물상자 3개를 열고 시작, 시작하면 소모된다. `save.supply`
- 둘 다 `myPower()`로 power 객체에 실려 협동 시 방장에게 전달된다 (`slots`, `supply`).

## 협동 구조
방장 폰이 게임 전체를 계산한다. 게스트는 자기 캐릭터 위치만 직접 움직여 보내고,
방장이 게스트마다 초당 20회 보내는 스냅샷(그 게스트 화면 근처의 적·투사체만, 바이너리)을 받아 부드럽게 보간해 그린다.
경험치와 레벨은 공유하고, 레벨업·보물상자 보상은 각자 고른다. 누군가 선택 중이면 잠시 멈추고 "3P가 고르는 중…"처럼 표시된다.
쓰러지면 동료가 곁에 2.5초 서 있거나 20초가 지나면 부활하고, 모두 쓰러지면 끝난다. 스테이지는 방장이 열어 둔 곳 중에서 고른다.

## 실행
```
npm install
STATIC_DIR=. PORT=8080 node server.js
```
밸런스 시뮬레이션: `?sim=1&chars=knight,mage&stages=1,5,10&pw=0,3,5&vac=1&duo=mage,rogue` (`pw`는 파워업 단계, `duo`는 봇 동료 최대 3명, 결과는 `#simout`에 JSON).
화면 확인: `?shot=knight&duo=mage,dwarf&stage=8&t=135&ui=freeze`.
